# Soul Maze · S3D-M1-03

基于 Three.js 的第一人称连续移动 3D 迷宫生存原型。玩家进入一座昏暗的固定迷宫，收集灵魂碎片、躲避巡逻与追逐的敌人，并在碎片集齐后找到出口。

## 启动

需要 Node.js 18+（本次环境：Node.js v24.19.0、npm 11.17.0）。在本目录执行：

```bash
npm install
npm run dev
```

Vite 会输出本地地址（通常为 `http://localhost:5173`），在浏览器打开即可。停止服务器：运行终端按 **Ctrl+C**。生产构建检查：`npm run build`；查看构建产物：`npm run preview`。

Three.js 和 Vite 使用本地 npm 依赖；游戏运行不依赖在线 AI、账号、后端或 CDN。

## 操作

- 点击 **进入迷宫**：开始正常游戏并请求鼠标锁定。
- **W/A/S/D**：按当前视线方向连续移动和横向移动。
- **鼠标**：控制水平和垂直视角；垂直视角会被限制，避免翻转。
- **Shift**：冲刺。冲刺消耗耐力，松开后耐力自动恢复。
- **Esc**：退出 Pointer Lock 并暂停；点击 **继续游戏** 可重新锁定并恢复。
- 右上角按钮或 **M**：切换静音。
- 菜单的 **Watch Demo**：无须鼠标操作，自动进行连续移动、收集和敌人行为演示；可点击底部 **退出** 或在 Demo 中按 Esc 返回菜单。

## 游戏规则

1. 在迷宫中收集 10 个灵魂碎片，每个碎片只能收集一次。
2. HUD 显示碎片进度、耐力、计时和敌人状态。
3. 出口初始为红色锁定状态；收集全部碎片后变为绿色并在 HUD 中提示。
4. 进入解锁后的出口区域即可胜利。
5. 敌人抓到玩家后失败；失败和胜利界面都可以重新开始或返回菜单。
6. 重新开始会重置玩家、敌人、路径状态、碎片、出口、计时、耐力和游戏状态。

## 技术实现

### 地图与碰撞

- `src/main.js` 的 `createFixedMap()` 通过固定墙段数据生成 32×32 字符地图；没有随机生成。
- 外围完整封闭，内部墙段带有多个缺口，形成环路、分支和可绕行路线。
- 启动时校验地图尺寸、外围墙、玩家/敌人出生点、碎片、出口和关键点 BFS 可达性。
- 玩家位置使用浮点世界坐标，不锁定在格子中心。
- 玩家碰撞体是独立的圆形半径；墙体碰撞使用圆形与墙体 AABB 检测。
- 移动被切成小步并分别处理 X/Z 轴，支持贴墙滑动并避免冲刺穿墙。
- 敌人也使用连续世界坐标和相同的墙体碰撞方式。

### 第一人称控制器

- 使用 `THREE.PerspectiveCamera`。
- Pointer Lock 只在用户点击开始或继续时请求。
- Pointer Lock 退出后进入暂停状态，菜单/结算/Demo 不响应正常玩家移动输入。
- 鼠标灵敏度、FOV、眼睛高度、速度、加速度、减速度、碰撞半径都集中在 `CONFIG`。
- 默认 FOV 为 80°，鼠标灵敏度为 `0.0022`，垂直视角限制为约 ±82.8°。

### 敌人 AI

敌人状态包括：

- `PATROL`：沿固定巡逻点移动。
- `CHASE`：在距离、视角和墙体无遮挡都满足时追逐玩家。
- `SEARCH`：失去视线后前往玩家最后出现的位置搜索一段时间。
- `RETURN`：搜索失败后返回巡逻路线。

敌人使用可通行格上的 A* 计算路线，但沿路径以连续世界坐标移动。视线检测使用距离、视野夹角和采样墙体遮挡检查，不把单纯距离检测当作视线。

### 模型替换接口

- `createWallVisual()`
- `createEnemyVisual()`
- `createFragmentVisual()`
- `createExitVisual()`

游戏逻辑使用独立的世界坐标、地图坐标和碰撞半径。未来替换正式模型时，主要修改视觉创建函数，不需要重写移动、收集、寻路或胜负逻辑。

## 声音

使用 Web Audio API 生成原创反馈音效：

- 收集碎片：高音反馈
- 敌人发现：低频警告
- 失败/胜利：结果音效
- 游戏运行时：低音环境氛围

首次开始游戏需要用户点击以满足浏览器自动播放策略。静音后会停止环境音和反馈音，取消静音会重新启用。

## 未测试与已知限制

当前执行环境没有可用的 Chrome、Edge、Chromium 或 Firefox 可执行文件，因此以下内容没有被宣称为浏览器实测通过：

- Pointer Lock 实际锁定/退出
- 鼠标视角移动和 Esc 暂停
- 不同刷新率下的实际移动手感
- 冲刺耐力条和连续碰撞的真实试玩
- 敌人巡逻、视线遮挡、追逐和搜索的浏览器交互
- Web Audio 实际听感
- Demo 完整试玩

已知限制：

- 只有一个固定关卡和一个敌人。
- 敌人 AI 是课程原型级 A*、视线和状态机，不是复杂行为树。
- 没有正式 3D 模型、动画、粒子或高成本后处理。
- 环境音是简单合成音，不是外部音频资源。
- `requestPointerLock()` 受浏览器权限和用户手势策略影响；若浏览器拒绝锁定，仍可运行键盘控制，但不会获得鼠标视角体验。
