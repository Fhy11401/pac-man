# 永夜旅馆 / THE NIGHT HOTEL · v2.8.1

一个以旧旅馆为背景的第一人称恐怖迷宫课程原型。收集记忆碎片，躲避巡夜人，完成收集后返回入口。

## 运行

使用 Node.js 18+：

```sh
node server.mjs
```

访问 <http://127.0.0.1:5182/>。Windows 可双击 `START_GAME.cmd`，启动器支持 Node.js 或 Python 3。游戏依赖、贴图与音频已随项目提供；不要直接打开 `index.html`。

## 操作

| 功能 | 按键 |
| --- | --- |
| 移动 / 视角 | WASD / 鼠标 |
| 奔跑 | Shift |
| 平滑掉头 | 鼠标中键 |
| 展开或收起地图 | Space |
| 暂停 | Esc |
| 静音 | M |

三条生命；受击后保留已收集的碎片。默认使用随朝向旋转的局部地图。主页开发者选项提供画面、地图与操作参数，调整仅在当前页面有效，刷新恢复固定默认值。

## v2.8.1

本版细化入口走廊、材质与局部照明，改善水晶表现和场景几何。此前版本已更新敌人细节、地图设备、菜单与镜头稳定性。

## 开发与验证

- `src/`：游戏逻辑、渲染、音频及界面。
- `assets/`：材质与音频；`vendor/`：随附运行依赖。
- `tests/`：移动、碰撞、追逐、地图、资源与渲染逻辑测试。

```sh
node --test tests/*.test.mjs
```

开场含中英文内容提示。游戏包含追逐和突发惊吓；桌面键盘与鼠标为当前支持方式。
