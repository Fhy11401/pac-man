# 回声档案 · 永夜回廊 v2.2.1

本地运行的 Three.js 第一人称迷宫追逃游戏。沿通道收集 106 枚回声，再回到入口撤离；一张固定地图、一名追逐敌人、三次机会。目标人工单局约 1–3 分钟，实际时长取决于路线与操作。

## 启动

无需 npm 安装或互联网。Three.js 0.180.0 与 MIT 许可证已随源码保存在 `vendor/`。

1. 解压完整文件夹，双击 `START_GAME.cmd`。
2. 在 Edge 或 Chrome 打开 `http://127.0.0.1:5180/`。
3. 保持服务器窗口运行；结束时在窗口按 Ctrl+C。

也可以在此目录运行 `node server.mjs`（Node.js 18+），或 `python -m http.server 5180 --bind 127.0.0.1`（Python 3）。不要直接双击 `index.html`，浏览器会限制本地文件下的模块加载。端口被占用时，请先检查是否已运行游戏；PowerShell 可用 `$env:PORT=5183; node server.mjs` 换端口。

## 操作

| 功能 | 操作 |
| --- | --- |
| 移动 | WASD |
| 转向 | 鼠标；备用为按住左键拖动或 ← → |
| 奔跑 | 按住 Shift，无体力限制 |
| 收起 / 展开手持地图 | Space，或左下角提示按钮 |
| 地图缩放 | Tab，在全图和局部放大之间切换 |
| 暂停 / 释放鼠标 | Esc |
| 静音 | M，或设置中的声音按钮 |
| 设置 | 主菜单“游戏设置”，或暂停菜单 |
| 重开 | 暂停菜单或结算界面 |

可调整视野、灵敏度、镜头起伏、地图缩放与默认奔跑。启用默认奔跑后，按住 Shift 改为步行。设置保存在当前浏览器；无账号、网络请求或外部存储。切换标签或失去焦点会自动暂停。仅支持电脑键盘与鼠标。

## 规则与反馈

- 回声连续分布在 106 个可通行格中，经过即收集；接近走廊侧面也能拾取。手持设备显示**剩余数量**。
- 地图显示墙、剩余回声与入口；不显示敌人。地图内容随视角旋转，玩家箭头始终朝上。全图模式保持全部通道可见；Tab 切换局部放大，玩家固定在地图中央。
- 三条命。碰撞扣命后原地停住，先用约 0.22 秒沿最短方向转向敌人的真实位置，再播放扑脸冲近动画；整个受击过程约 1.1 秒，淡到黑场后再回到入口；接着约 1.4 秒显示重生提示，保留收集进度。最后一条命也先播放惊吓再显示失败。敌人重生后另有 1.2 秒起跑间隔。
- 开局敌人延迟约 3.2 秒开始追逐。沿真实可通行路线追击，不穿墙或瞬移。
- 集齐后进入撤离阶段：设备提示返回入口，入口变绿，敌人速度提高。到达入口才成功。
- 前向红色聚光随敌人行进方向转动，照到地面与墙面；实体墙遮挡，便于在转角前预警。
- 玩家和敌人的脚步都按真实位移触发，停止或撞墙时不原地踏步。敌人脚步加强低频撞击与鞋底擦响，按方向声像与距离衰减；隔墙仍可听见较弱的声音。
- 7.5 格内出现双拍心跳，越近越响、越快；近距离间歇播放敌人叫声。惊吓使用短促吼叫与低频冲击，输出经过动态压缩；暂停和静音会停止相应声音。所有音效均为本地合成。
- 拾取有短促音效、晶体消散和计数变化，不再每拾取一枚就弹出遮挡视线的通知。
- Space 可收起手机式地图。展开时设备位置固定，移除机身的行走起伏与转向摆动；转头会旋转屏幕内部的地图。镜头起伏支持关闭。系统“减少动态效果”优先禁用动态镜头效果。

## 本版参数

以下是为本地图调校的参数，不声称是《黑暗欺骗》的原始数值。

- 每格 2.4 m；步行 1.45 格/秒（3.48 m/s），奔跑 2.5 格/秒（6.0 m/s）。
- 普通追逐 1.85 格/秒（4.44 m/s），撤离追逐 2.15 格/秒（5.16 m/s）。敌人快于步行，慢于奔跑。
- 移动加速 26 格/秒²；奔跑约 0.1 秒达速，松键立即停止。斜向输入归一化，没有斜向加速。
- 默认视野 94°，奔跑平滑增加最多 3°；在宽屏下按水平视野计算，窄窗口限制垂直扩张，避免纵向透视被过度拉大。
- 眼高 1.69 m，步行起伏最大约 ±1.8 cm，奔跑约 ±3.2 cm，不强制画面倾斜。

## 自动 Demo

主菜单“观看完整通关”自动完成整场游戏，随后显示结果约 7 秒并返回菜单。当前自动路线在 15 / 30 / 60 / 144 FPS 模拟下约 74–94 秒有效游戏时间、剩余 3 条命完成通关（另有可能发生的死亡重生等待）。

路线在拐角走小弧线；镜头提前看向转角，将转角误差换成虚拟鼠标滑动，缓慢起转、加速、接近目标时减速，避免突然停转。急转时减速、掉头先转身，遇到前方敌人会选择退让路线。演示摇晃幅度为正常游玩的 65%。

Demo 只提供普通移动输入，被抓住时保留进度并继续探索。它没有免死、瞬移、特殊速度、填满收集物或跳过出口的逻辑。可重播、退出、切换地图缩放或静音；按 Esc 退出演示。超时 180 秒会显示未完成，不伪报通关。

## 开发结构与检查

- `src/world.js`：地图、连续收集路线、参数与寻路。
- `src/core.js`：人工与 Demo 共享的移动、碰撞、追逐、生命和结局规则。
- `src/demo.js`：普通移动输入的自动控制器。
- `src/view.js`：场景、程序生成材质、敌人动画、红光阴影、相机与地图。
- `src/audio.js`：合成音效、移动脚步、敌人方向和距离反馈。
- `src/presentation.js`：长帧保护、死亡转向与扑脸时序。
- `src/map-view.js`：随朝向旋转的地图、局部居中、底图缓存。
- `src/hotel-detail.js`：护墙板、天花线脚、灯具、原创程序绘制画作与导视。
- `src/look-input.js`：鼠标锁定与拖动输入、异常位移过滤和松键清理。
- `src/main.js`：输入、设置、暂停、菜单、HUD 与渲染循环。
- `src/style.css`：菜单和手持地图界面。

运行 `npm test` 或 `node --test tests/*.test.mjs`。39 项自动检查包含四个帧率的完整通关、三次接触扣命、进度保留、未收集完不能撤离、重开重置、墙体碰撞、人工与 Demo 同规则、奔跑与松键停步、撤离敌人加速、偏离通道中心时的拾取，集齐后死亡不能自动获胜，四种帧率下的镜头转速上限和无反向滑行、碰撞位置冻结与黑场后重生、最后一条命的惊吓流程、移动位移上限、长帧保护、音效距离曲线、任意朝向的地图投影、全图边界与死亡转向先后顺序。

机器检查不等同于真人试玩。手感、音量、实际玩家难度仍需团队亲自验证，不能将这些自动检查作为课程要求的外部反馈或 NO AI 迭代记录。

## v2.1.1 转向修复与移动验收

- 未锁定鼠标时，用连续的页面坐标计算拖动距离，避免浏览器异常 `movementX` 导致突然转头。仅按住左键时转向；指针捕获、松键、取消或失焦都会清理拖动状态。
- 锁定鼠标后的首个重定位事件和异常尖峰被丢弃；正常快速滑动保留。
- 新增鼠标输入回归、转向加减速、全地图弯道碰撞与拾取，以及变帧率完整 Demo 检查。
- 浏览器键盘操作实测：前后和左右移动、冲刺、斜走、贴墙、边走边用方向键转向、鼠标拖动后松键再前进。步行峰值 3.48 m/s、奔跑 6 m/s；斜走未超速，松键后速度为 0，未检测到非重生位置跳变。鼠标拖动后的朝向为 −101.34°，松键并再次移动鼠标、前进后保持不变。
- 为避免测试标签后台绘制节流，浏览器移动验收使用独立副本的 16 ms 定时驱动；生产版本仍使用 `requestAnimationFrame`。这验证输入和物理行为，不是生产帧率基准。
- 主菜单与暂停菜单显示版本。若仍看到 2.0，请打开新版页面；刷新会丢失当前局进度。

## 行走流畅度修复

- 固定地图的普通寻路预建 BFS 缓存；Demo 每段规划只计算一次加权路径树，避免为每个碎片重复搜索。
- 将重复墙边装饰、灯具和门框合并为实例绘制；提前编译场景与惊吓材质。
- 小地图底图只在收集状态变化时重绘，收起时停止绘制。
- 超过 90 ms 的卡顿帧不再一次补走整段时间；正常 15–144 FPS 的时间步长保留。后台切换仍会暂停。

v2.1 的历史开发对照（非 v2.2 性能测量）：渲染 CPU 95 分位从 3.9 ms 降到 1.4 ms，最多绘制调用从 234 次降到约 73 次。Demo 单帧模拟最坏值从约 58.7 ms 降到约 5.3 ms。这是本机自动化开发测量，不是所有电脑的帧率保证，也不是课程真人试玩记录。
