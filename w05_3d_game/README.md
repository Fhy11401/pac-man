# 永夜旅馆 / THE NIGHT HOTEL · v2.10.0

一个以旧旅馆为背景的第一人称恐怖迷宫课程原型。收集记忆碎片，躲避巡夜人，完成收集后返回出口。随游戏提供地图编辑器，可创建草稿并独立试玩。

## 运行

使用 Node.js 18+：

```sh
node server.mjs
```

访问 <http://127.0.0.1:5182/>。Windows 完整解压后，可双击同一目录内的两个入口：

- `START_GAME.cmd`：启动游戏。
- `START_EDITOR.cmd`：启动地图编辑器。

启动器支持已安装的 Node.js 或 Python 3，自动选择可用端口并复用本目录的服务。游戏依赖、贴图与音频已随项目提供，无须安装 npm 包；不要直接双击 HTML 文件。载入期间会显示动画、材质进度及画面准备阶段，完成后显示中英文内容提示。

## 地图编辑器

`editor.html` 与两个启动脚本位于同一目录。编辑器可绘制通道和墙体，增减水晶、格间隔墙，拖动出生点、敌人与出口；安全屋及木板入口结构保持锁定。直线工具适合拉长通道，短折弯提示可定位需要调整的路段。

- 点击 **试玩草稿**，在新标签页运行当前地图；编辑器后续修改不会影响已打开的试玩。
- 点击 **还原默认地图**，恢复内置布局、显示设置和画布位置；误点后可用 `Ctrl+Z` 找回刚才的地图。
- **旧图预设**保留上一版布局和同学原图；载入原图时会保留安全屋入口结构。
- 草稿自动保存到当前浏览器地址。使用 **导出 JSON** 备份或发给组员，再用 **导入 JSON** 继续编辑；换浏览器、地址或电脑时请使用 JSON 文件。
- **导出 PNG** 可生成高清平面图。`DEFAULT_MAP.json` 为随包提供的默认地图备份，也可直接导入。

通道断连或目标位置无效时会暂停试玩入口，草稿仍可继续编辑和导出。`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，滚轮缩放，按住空格拖动画布。普通游戏入口始终使用内置地图，不读取编辑器草稿；游戏内开发者参数仍只在当前页面生效。

## 操作

| 功能 | 按键 |
| --- | --- |
| 移动 / 视角 | WASD / 鼠标 |
| 奔跑 / 冲破入口木板 | Shift |
| 近距离拆开入口木板 | E |
| 平滑掉头 | 鼠标中键 |
| 展开或收起地图 | Space |
| 暂停 | Esc |
| 静音 | M |

三条生命；受击后保留已收集的碎片。默认使用随朝向旋转的局部地图。主页开发者选项提供画面、地图与操作参数，调整仅在当前页面有效，刷新恢复固定默认值。

## 默认关卡

默认关卡使用已编辑确认的布局，出口位于接待处木板入口外。迷宫共有 257 枚碎片；开场安全屋不放置碎片，只有一个木板入口。靠近后按 E，或按住 Shift 向前冲破木板，即开始计时并在短暂延迟后进入追逐。安全屋允许暂避；受击重生保留碎片和本局已开启的入口。

默认地图不设置通道内的固定隔断；普通墙体和开场可破木板保留。局部地图保持清晰的通道比例，全图适配矩形布局，场景包含接待处、区域和出口标识。

地图对比页位于 `/review.html`，可查看历史地图、当前默认地图和改动叠加。旧图可从编辑器预设中载入并试玩，全部入口使用当前本地服务。

## 开发与验证

- `src/`：游戏逻辑、渲染、音频及界面。
- `assets/`：材质与音频；`vendor/`：随附运行依赖。
- `tests/`：移动、碰撞、追逐、地图、资源与渲染逻辑测试。

```sh
node --test tests/*.test.mjs
```

开场含中英文内容提示。游戏包含追逐和突发惊吓；桌面键盘与鼠标为当前支持方式。
