# 永夜旅馆 / THE NIGHT HOTEL

正式版：v2.13.0。第一人称旅馆潜行游戏：修复酒店供电，利用真实摄像头、客房和电话避开巡夜人，活着回到监控室并合上机械门。

默认酒店为 56 × 40 格，其中 482 格可通行，包含四个大厅、两间客房和十路公共区域摄像头。监控界面采用 CRT 夜班值守风格，手持设备采用手机界面，随游戏提供完整酒店布局编辑器。

## 运行

完整解压后，双击同目录中的 `START_GAME.cmd`。完整酒店编辑器入口为 `START_EDITOR.cmd` 或 `START_HOTEL_EDITOR.cmd`。启动器使用已安装的 Node.js 或 Python 3，自动选择可用端口；素材与运行依赖已随包提供，无须安装 npm 包。请通过本地服务打开，不要直接双击 HTML。

也可以使用 Node.js 18+：

```sh
node server.mjs
```

浏览器打开终端显示的本地地址。首次加载会显示资源准备进度，完成后显示中英文惊吓提示。

## 操作

| 功能 | 按键 |
| --- | --- |
| 静音行走 / 视角 | WASD / 鼠标 |
| 奔跑 | Shift，实际奔跑会发出可被敌人听见的脚步声 |
| 平滑掉头 | 鼠标中键 |
| 机械门、备用电池 | 靠近并面向目标，按 E |
| 客房门快速开关 | 短按 E；鼠标锁定时也可短按左键。操作有声，前摇约 0.18 秒 |
| 客房门安静开关 | 持续按住 E 或锁定鼠标后的左键 1.2 秒 |
| 躲入 / 离开床底 | 靠近床侧并面向床，按 E；床底可转头、操作手机与监控 |
| 维修配电箱 | 靠近并按住 E，累计 8 秒，可中断 |
| 操作手机 / 返回观察 | Tab，可点击手电或监控按钮；床底使用后仍保持藏身 |
| 远程监控 | M，可在任意位置接入；连接需 1.25 秒 |
| 选择摄像头 | 点击频道，或监控中按 ← / → |
| 夜视仪 | Q 独立切换，初始 90 秒电量 |
| 手机手电 | F，无限电量，与夜视互斥 |
| 201 / 202 客房电话 | 1 / 2，响铃 7 秒，冷却 14 秒 |
| 退出监控 / 取消连接 | Esc 或 M |
| 暂停 | 正常行走时按 Esc |

手机在正常游玩时始终显示。操作手机、连接和查看监控时，玩家停止移动，敌人仍会行动；Tab 返回游戏操作。接入监控会关闭手电与夜视，Q 独立操作夜视。退出监控后恢复玩家视角与鼠标操作；床底藏身不会因此解除。

选择摄像头后，楼层图以浅绿色标出当前镜头的参考范围，并随门的开关更新。提示考虑镜头朝向、视角及墙门遮挡；它是地面采样示意，不表示家具后方或暗处的物体一定清晰可见。

夜视电池仅在开启时消耗。客房中的备用电池按 E 拾取，每块补充最多 40 秒，满电时保留。声音开关位于游戏设置。

## 体验与调试设置

- **友好模式**：可在开场惊吓提示页或游戏设置中选择，默认开启。开启后，跳杀画面使用马赛克，并显示敌人前方红光；仅影响画面呈现，不改变追逐、死亡或生命扣除规则。
- **敌人透视（调试）**：位于主页开发者选项，默认关闭，可随时开启。用于穿墙定位敌人；开发者选项中的“恢复默认值”会将其重新关闭。

这两项设置及主页开发者参数仅在当前页面生效，不保存本地偏好。刷新后恢复固定默认值：友好模式开启，敌人透视关闭。

## 关卡规则

- 开场约 20 秒：先观察监控中的巡夜人停步、察觉镜头并靠近，短暂停顿后扑向镜头并断电，再经历备用电源启动；随后出现主角界面并收到主管来电。接听后播放约 54 秒的英文配音与电影式中文字幕；可拒接或挂断跳过指引。音频加载失败时回退为同一短稿字幕。监控室的备用供电不代表已完成酒店维修目标。
- 接待大厅、西侧休息厅、宴会大厅和东侧中庭通过长走廊及环路连接。两间客房可供藏身，独立监控室是维修后的返程地点。
- 十路真实三维摄像头用于观察大厅和主要交通节点，客房内部不设摄像头，走廊也保留盲区。墙和关闭的门会遮挡画面；酒店停电时使用红外画面，恢复供电后切换彩色。
- 普通行走不会留下脚步声；实际奔跑、维修和快速开门会产生可调查的声音，受路线距离和门的遮挡影响。电话铃声按距离与遮挡改变响度，远处仍然可闻。
- 夜视不向环境发光。手电及其受照区域可能引起调查；恢复酒店照明后，敌人可以在灯下看见玩家。失去线索后，敌人会搜索再恢复巡逻。
- 1 / 2 可以远程拨响客房电话，全酒店都能听到。非追逐中的巡夜人会到相应客房查房；追逐或已目击藏身位置时忽略该通电话，响铃不会反复重置查房。
- 客房床侧按 E 可钻到床底，保持低视角观察，仍可使用手机和监控；再次按 E 离开。直接被目击钻入床底时，敌人会记住藏身处。
- 敌人因目击或电话线索到达关着的客房门后，会连续砸门约 5 秒再开门入室，近处可听到撞击并看到破门进度提示。未发现床底玩家时会在房内搜索，随后离开；监控室机械门仍不能被敌人打开。
- 机械门可从两侧开关，关闭会阻挡通行与视线，门轨有人时拒绝关闭。监控室有备用供电，但开门时敌人仍能进入。
- 维修进度可以累积。供电恢复后，返回监控室主体区域并关闭机械门，确认敌人在门外，即完成本次夜班。
- 三条生命，受击保留维修进度和已消耗的资源。死亡回到监控室不算成功撤离，需要再次出门并安全返回。

通道默认净宽为 2.0 米。当前目标是修复供电并返回监控室，水晶不参与通关条件；移动、惯性与镜头参数可在开发者选项中调整。

## 完整酒店编辑器

通过启动器或本地服务中的 [hotel-editor.html](hotel-editor.html) 打开。编辑器与游戏使用同一份完整默认布局，既能修改地形，也能移动设施、客房与摄像头，并设置大厅类型和镜头朝向。[查看默认布局图片](HOTEL_LAYOUT.png)。

- 用通道、墙体或矩形工具编辑地面；大厅工具建立真正开放的大厅区域。
- 拖动物件改变位置，在属性栏修改朝向。移动客房会同时移动门、电话和房内电池，门外连接需要接回走廊。移动大厅保留原有地面，方便衔接路线。
- 按 H 选择拖图，或按住空格拖动；滚轮缩放，Ctrl+Z 撤销，Ctrl+Y 重做。
- 支持本机草稿保存、完整 JSON 导入导出、PNG 导出和还原默认布局。导入或还原也可以撤销。[HOTEL_DEFAULT.json](HOTEL_DEFAULT.json) 是随包提供的完整默认布局。
- 布局存在语义问题时仍可保存草稿；通过连通性、设施位置和入口等校验后才能试玩。

酒店编辑器的试玩使用真实停电规则，地形、设施、房门、家具与摄像头一起进入游戏。每次试玩使用独立快照，之后继续编辑不会改变已经打开的试玩。正常游戏入口始终使用内置默认布局，不自动读取本机草稿；调试参数仍只在当前页面生效。

旧版 [editor.html](editor.html) 保留为独立的收集地图编辑器，其草稿试玩继续使用水晶收集和木板入口规则。两种编辑器的文件格式、草稿和试玩入口分开保存。

## 开发与素材

```sh
node --test tests/*.test.mjs
```

`src/` 包含逻辑、画面、声音与界面；`tests/` 包含移动、地图、资源与玩法测试；`assets/` 和 `vendor/` 提供随包素材与运行依赖。版本变化及验证结论见 [版本说明](RELEASE_NOTES_v2.13.0.md)。

素材来源、作者与授权说明见 [REFERENCE_NOTES.md](REFERENCE_NOTES.md)，AI 协作范围见 [AI_ASSISTANCE.md](AI_ASSISTANCE.md)。主管通话的字幕与配音来源见 [语音说明](assets/audio/tutorial/README.md)。新增酒店设施和界面独立实现；既有第三方素材的归属和许可证保持原说明。

监控室设有完整酒店墙面图、六屏实景监控台与桌椅；多屏使用共享渲染器错峰更新，离开监控室后暂停额外渲染。家具参与实体碰撞，并保留通行与交互空间。

默认音乐音量为 32.5%，音效总线增益为 1.2；心跳和敌人脚步使用相同的距离及墙体衰减，靠近时心跳加速。追逐状态立即选择近敌曲目；脱离追逐后恢复距离规则。设置仅在本次页面生效。

心跳采用 InspectorJ 的录音素材，保留音高并按距离调整双拍间隔；来源、CC BY 4.0 许可与处理方式见 [心跳音效说明](assets/audio/heartbeat/README.md)。
