# 回声档案 · 永夜回廊 v2.5.1

本地运行的 Three.js 第一人称迷宫追逃游戏。沿通道收集 106 枚回声，再回到入口撤离；一张固定地图、一名追逐敌人、三次机会。目标人工单局约 1–3 分钟，实际时长取决于路线与操作。

## 启动

无需 npm 安装或互联网。Three.js 0.180.0 与 MIT 许可证已随源码保存在 `vendor/`。

1. 解压完整文件夹，双击 `START_GAME.cmd`。
2. 在 Edge 或 Chrome 打开 `http://127.0.0.1:5182/`。
3. 保持服务器窗口运行；结束时在窗口按 Ctrl+C。

也可以在此目录运行 `node server.mjs`（Node.js 18+），或 `python -m http.server 5182 --bind 127.0.0.1`（Python 3）。不要直接双击 `index.html`，浏览器会限制本地文件下的模块加载。端口被占用时，请先检查是否已运行游戏；PowerShell 可用 `$env:PORT=5183; node server.mjs` 换端口。

## 操作

| 功能 | 操作 |
| --- | --- |
| 移动 | WASD |
| 转向 | 鼠标；备用为按住左键拖动或 ← → |
| 奔跑 | 按住 Shift，无体力限制 |
| 收起 / 展开手持地图 | Space，或左下角提示按钮 |
| 地图缩放 | Tab，在全图和局部放大之间切换 |
| 暂停 / 释放鼠标 | Esc |
| 静音 | M，或设置中的声音按钮 |
| 设置 | 主菜单“游戏设置”，或暂停菜单 |
| 重开 | 暂停菜单或结算界面 |

游戏设置可调整音乐、镜头起伏开关、地图缩放与默认奔跑。主页“开发者选项”提供 16 个滑块：视野、亮度、步行与奔跑起伏、步行与奔跑速度、两种加速时间、换向与收势惯性、鼠标灵敏度与摩擦、普通与撤离追逐速度、通道净宽、眼高和身体宽度。通道宽度松开滑块后重建场景；其余参数即时应用。所有调整只在当前页面有效，刷新后恢复固定默认，不读取或写入本地设置。启用默认奔跑后，按住 Shift 改为步行。切换标签或失去焦点自动暂停。仅支持电脑键盘与鼠标。

## 规则与反馈

- 回声连续分布在 106 个可通行格中，经过即收集；接近走廊侧面也能拾取。手持设备显示**剩余数量**。
- 地图显示墙、剩余回声与入口；不显示敌人。地图内容随视角旋转，玩家箭头始终朝上。全图模式保持全部通道可见；Tab 切换局部放大，玩家固定在地图中央。
- 三条命。碰撞扣命后原地停住，先用约 0.22 秒沿最短方向转向敌人的真实位置，再播放扑脸冲近动画；整个受击过程约 1.1 秒，淡到黑场后再回到入口；接着约 1.4 秒显示重生提示，保留收集进度。最后一条命也先播放惊吓再显示失败。敌人重生后另有 1.2 秒起跑间隔。
- 开局敌人延迟约 3.2 秒开始追逐。沿真实可通行路线追击，不穿墙或瞬移。
- 集齐后进入撤离阶段：设备提示返回入口，入口变绿，敌人速度提高。到达入口才成功。
- 前向红色聚光随敌人行进方向转动，照到地面与墙面；实体墙遮挡，便于在转角前预警。
- 玩家和敌人的脚步都按真实位移触发，停止或撞墙时不原地踏步。敌人脚步加强低频撞击与鞋底擦响，按方向声像与距离衰减；隔墙仍可听见较弱的声音。
- 7.5 格内出现双拍心跳，越近越响、越快；近距离间歇播放敌人叫声。惊吓使用短促吼叫与低频冲击，输出经过动态压缩；暂停和静音会停止相应声音。所有音效均为本地合成。
- 拾取有短促音效、晶体消散和计数变化，不再每拾取一枚就弹出遮挡视线的通知。
- Space 可收起手机式地图。展开时设备位置固定，移除机身的行走起伏与转向摆动；转头会旋转屏幕内部的地图。镜头起伏支持关闭。系统“减少动态效果”优先禁用动态镜头效果。

## 本版参数

以下是为本地图调校的参数，不声称是《黑暗欺骗》的原始数值。

- 每格长度保持 2.4 m，通道实际净宽 1.50 m；墙面、门框、壁灯及碰撞边界同步内收。
- 身体碰撞半径 0.16 格，直径约 0.77 m；直通道居中时左右各可移动约 0.37 m。眼高 1.62 m。
- 步行 1.60 格/秒（3.84 m/s），奔跑 2.80 格/秒（6.72 m/s）。普通追逐 2.05 格/秒，撤离追逐 2.40 格/秒。
- 从静止到步行全速约 0.07 秒，起跑约 0.16 秒；默认换向与收势惯性 0.06 秒，范围 0–0.18 秒，设为 0 可关闭，无斜向加速。
- 固定视野 80°、亮度 70%。步行起伏 1.0 倍，奔跑 2.0 倍；前后左右均按实际位移起伏。
- 鼠标摩擦默认 28%：细小滑动略有阻力，快速转身阻力较小；没有延迟追随、停手惯性或丢弃细小输入的死区。
- 水晶覆盖所在通道格的完整可行走宽度，按实际移动线段检测，贴墙与转角也可拾取；不会提前吸走整条走廊或隔墙水晶。

## 开发结构与检查

- `src/tuning.js`：固定默认值、开发者滑块和单位显示。
- `src/world.js`：地图、连续收集路线、参数与寻路。
- `src/movement.js`：短惯性速度响应、连续圆形扫掠碰撞和墙面滑动。
- `src/core.js`：人工与 Demo 共享的移动、碰撞、追逐、生命和结局规则。
- `src/demo.js`：普通移动输入的自动控制器。
- `src/view.js`：场景、程序生成材质、敌人动画、红光阴影、相机与地图。
- `src/audio.js`：合成音效、移动脚步、敌人方向和距离反馈。
- `src/presentation.js`：长帧保护、死亡转向与扑脸时序。
- `src/map-view.js`：随朝向旋转的地图、局部居中、底图缓存。
- `src/hotel-detail.js`：护墙板、天花线脚、灯具、原创程序绘制画作与导视。
- `src/look-input.js`：鼠标锁定与拖动输入、异常位移过滤和松键清理。
- `src/main.js`：输入、设置、暂停、菜单、HUD 与渲染循环。
- `src/style.css`：菜单和手持地图界面。

运行 `npm test` 或 `node --test tests/*.test.mjs`。60 项自动检查包含四个帧率的完整通关、三次接触扣命、进度保留、未收集完不能撤离、重开重置、墙体碰撞、人工与 Demo 同规则、奔跑与松键停步、撤离敌人加速、偏离通道中心时的拾取，集齐后死亡不能自动获胜，四种帧率下的镜头转速上限和无反向滑行、碰撞位置冻结与黑场后重生、最后一条命的惊吓流程、移动位移上限、长帧保护、音效距离曲线、任意朝向的地图投影、全图边界与死亡转向先后顺序，新增配乐状态层次、遮挡与延迟退场、循环音轨振幅及音源生命周期。

## 行走流畅度修复

- 固定地图的普通寻路预建 BFS 缓存；Demo 每段规划只计算一次加权路径树，避免为每个碎片重复搜索。
- 将重复墙边装饰、灯具和门框合并为实例绘制；提前编译场景与惊吓材质。
- 小地图底图只在收集状态变化时重绘，收起时停止绘制。
- 超过 90 ms 的卡顿帧不再一次补走整段时间；正常 15–144 FPS 的时间步长保留。后台切换仍会暂停。
