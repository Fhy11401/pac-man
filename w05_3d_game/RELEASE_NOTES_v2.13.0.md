# v2.13.0 · 永夜旅馆

## 本次更新

- 完善分区供电后的撤离追杀，强化声音感知、调查打断和敌人行为优先级，加入明暗转角与短时路线记忆，完善声音调查的移动速度。
- 加入随机客房道具、单格持有与交换，以及防卫和侦听机制；补充独立小桌上的双语客房检查清单。
- 升级监控室多屏场景与第一人称开场，改善监控成像、敌人动作、身体照明及惊吓衔接；加强角色轮廓、追逐凝视及动作衔接，改善开场面部照明和惊吓停留节奏。
- 统一游玩、警告和暂停界面，精简重复操作入口，完善开场跳过、开场安全准备阶段、危险提示及操作限制。
- 升级高清监控成像、自动扫描、墙面回弹及可见目标跟踪；同步监控地图与敌人标记，完善退出及视角恢复。
- 简化手机收放与按键操作，完善开场敌人激活规则及机械门撞击后放弃的行为。
- 更新与音频同步的心跳视觉反馈。
- 优化公共区域摄像头布置与关键设施覆盖，保留开场镜头；同步酒店编辑器默认设施与监控地图。
- 同步酒店编辑器的供电分区、设施编辑、布局兼容及试玩校验。
- 调整室内外威胁音效与背景音乐平衡。
- 优化多屏渲染调度、监控扫描缓存和动画连续性，减少重复计算与临时分配；修正危险提示的触发时机。

验证：470 项自动化测试通过，覆盖监控成像与追踪、关键区域覆盖、手机操作、敌人感知、机械门行为及开场兼容性。
