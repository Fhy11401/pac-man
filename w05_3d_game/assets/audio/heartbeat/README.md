署名："Heartbeat, Regular, Single, 01-01, LOOP.wav" by InspectorJ (www.jshaw.co.uk) of Freesound.org.

本项目保留录音的原始音高，在运行时分取两段脉冲，调整间隔、音量和淡入淡出以适应游戏距离与心率，并通过低频与中高频均衡改善清晰度、匹配敌人脚步的响度。该素材不是本项目原创，也不是 CC0。加载失败时使用程序合成心跳回退。
