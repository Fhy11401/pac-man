# 永夜旅馆 / THE NIGHT HOTEL · v2.10.0

第一人称恐怖迷宫收集游戏。默认关卡包含 257 枚记忆碎片，玩家从安全屋进入迷宫，躲避巡夜人，集齐后返回出口；三次生命机会，受击后保留收集进度。

开发分支：`feature/echo-archive`。项目源码及随附地图编辑器位于 [w05_3d_game](w05_3d_game/)。

## 启动

1. 下载或克隆本分支，进入 `w05_3d_game`。
2. 双击 `START_GAME.cmd` 玩游戏，或双击 `START_EDITOR.cmd` 编辑地图。
3. 启动器会选择可用端口并打开对应页面；重复启动会复用本目录的服务。

需要已安装 Node.js 或 Python 3。运行资源已随项目提供，无需安装 npm 依赖；请通过本地服务器访问页面。也可运行 `node server.mjs`，访问 <http://127.0.0.1:5182/>。
