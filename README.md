# 永夜旅馆 / THE NIGHT HOTEL · v2.7.2

你接下旅馆的第一班夜勤。找回旅客遗落的 **106 枚记忆碎片**，避开巡夜人，回到大堂。一张地图、一名敌人、三次机会；被抓后保留收集进度。

个人版本固定使用 **`feature/echo-archive`** 分支，源码位于 [w05_3d_game](./w05_3d_game/)。本次从远端 v2.5.1 更新至 v2.7.2，累计改动详见 [CHANGELOG.md](./CHANGELOG.md)。

## 启动

1. 下载或克隆本分支，进入 `w05_3d_game`。
2. 双击 `START_GAME.cmd`，或运行 `node server.mjs`（Node.js 18+）。启动脚本也支持已安装的 Python 3。
3. 打开 [本地游戏](http://127.0.0.1:5182/)，保持服务器窗口运行。

Three.js、贴图和两首配乐已附带，无需 npm 安装或互联网。请通过服务器打开，勿直接双击 `index.html`。每次打开页面先显示中英文惊吓提示，确认后进入主菜单。

## 操作

| 功能 | 操作 |
| --- | --- |
| 移动 / 转向 | WASD / 鼠标；未锁定时可按住左键拖动 |
| 奔跑 | Shift |
| 平滑掉头 180° | 鼠标中键，默认 0.32 秒 |
| 收起 / 展开地图 | Space |
| 暂停 / 静音 | Esc / M |

默认局部地图随视角旋转，玩家居中，机身稳定。全图切换、地图倍率、掉头时长与转向稳像均在主页开发者选项；Tab 不再切换地图。全部调试仅在当前页面有效，刷新恢复源码固定默认。
