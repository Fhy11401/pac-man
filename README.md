# 永夜旅馆 / THE NIGHT HOTEL · v2.8.1

第一人称恐怖迷宫收集游戏。扮演旅馆夜班职员，找回 106 枚记忆碎片，避开巡夜人并返回大堂；三次生命机会，受击后保留收集进度。

开发分支：`feature/echo-archive`。项目源码位于 [w05_3d_game](w05_3d_game/)。

## 启动

1. 下载或克隆本分支，进入 `w05_3d_game`。
2. 双击 `START_GAME.cmd`，或使用 Node.js 18+ 运行 `node server.mjs`。
3. 打开 <http://127.0.0.1:5182/>，保持服务器运行。

运行资源已随项目提供，无需安装 npm 依赖。请通过本地服务器访问页面。启动器也支持 Python 3。
