# 回声档案 · 永夜回廊 v2.5.1

Three.js 第一人称迷宫追逃游戏。收集 106 枚水晶后返回入口，躲避一名敌人；共有三条命，被抓住后保留收集进度。

本分支为个人版本，源码位于 [w05_3d_game](./w05_3d_game/)。这次从已上传的 v2.2.1 更新至 v2.5.1，完整改动与验证记录见 [CHANGELOG.md](./CHANGELOG.md)。

## 启动

1. 下载或克隆本分支，进入 `w05_3d_game`。
2. 双击 `START_GAME.cmd`，或运行 `node server.mjs`（需要 Node.js 18+）。
3. 打开 [本地游戏](http://127.0.0.1:5182/)，保持服务器窗口运行。

Three.js 和许可证已附带，无需安装 npm 依赖或连接互联网。不要直接双击 `index.html`。

## 操作

WASD 移动，鼠标转向，Shift 奔跑，Space 收起地图，Tab 缩放地图，Esc 暂停，M 静音。主页已移除“观看完整通关”入口。

## 本次更新

- 通道实际收窄至 1.50 米，墙面、装饰和碰撞边界同步调整；身体宽度约 0.77 米，眼高 1.62 米。
- 水晶覆盖经过通道格的完整宽度，贴墙和转角也能拾取，不会隔墙吸取。
- 碰撞改为连续检测并沿墙滑动，改善横移和转角顿挫；新增默认 0.06 秒的换向与收势惯性。
- 步行、奔跑和敌人速度略增，保留短起跑加速；奔跑起伏默认 2.0 倍，前后左右移动都有起伏。
- 鼠标增加可调摩擦，过滤异常位移，停手后不继续转动。
- 固定默认视野 80°、亮度 70%；完善酒店材质、墙边装饰、局部照明和拐角预亮。
- 加入探索、紧张、追逐、撤离四层原创动态配乐，与脚步、心跳、敌人叫声配合。
- 主页开发者选项集中提供 16 个滑块。测试调整只在当前页面有效，刷新恢复默认，不读取或写入本地设置。

## 验证与文档

在 `w05_3d_game` 运行 `npm test` 或 `node --test tests/*.test.mjs`：**60 项自动检查通过**。浏览器验证涵盖贴墙滑动、四向移动、调试参数、场景重建和刷新恢复默认。自动检查不替代真人手感与难度试玩。
