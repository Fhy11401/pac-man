# 回声档案 · 永夜回廊 v2.2.1

Three.js 第一人称迷宫收集与追逃游戏。收集 106 枚回声后返回入口，躲避一名追逐敌人；共有三条命，死亡保留收集进度。

本分支保存当前独立版本，完整源码位于 [w05_3d_game](./w05_3d_game/)。

## 启动

进入 `w05_3d_game`，双击 `START_GAME.cmd`，随后打开 http://127.0.0.1:5180/ 。也可以在该目录执行 `node server.mjs`（Node.js 18+）。Three.js 已随源码附带，无需安装 npm 依赖。

## 操作

WASD 移动，鼠标转向，Shift 奔跑，Space 收起地图，Tab 缩放地图，Esc 暂停，M 静音。主菜单可观看自动通关 Demo。
